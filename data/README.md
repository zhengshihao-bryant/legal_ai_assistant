# 法律知识助手 · 演示数据集

本目录是「法律知识助手」RAG 系统的演示数据集,面向文档入库、语义检索与智能问答测试。

## 结构

```
data/
├── raw/                    # 原始文档(入库源文件)
│   ├── laws/               # 法律法规官方 PDF(国家法律法规数据库下载)
│   ├── policies/           # 企业制度(演示用示例制度,共28份,md + docx)
│   ├── contracts/          # 合同模板(演示用,共7份,md + docx)
│   └── cases/              # 案例库(演示用模拟案例,共4份,md + docx)
├── parsed/                 # RAG 管线输出:解析后的纯文本(当前为空)
├── chunks/                 # RAG 管线输出:切块结果(当前为空)
└── evaluation/qa.json      # 问答评估集(100 条)
```

## 文档来源与真实性说明

- **laws/**:全部来自官方**国家法律法规数据库** `https://flk.npc.gov.cn`,为官方原文(中文法律法规属公版文本,公开可下载)。下载明细、版本(公布/施行日期)、bbbs 编号见 `laws/download_report.md`。当前共 **19 部**(规划 18 部 + 2025 年《劳动争议司法解释(二)》)。
- **policies/、contracts/、cases/**:均为**演示用模拟内容**,基于虚构公司「华创智联科技有限公司」,每份文档已逐份标注。不构成法律意见,不得用于真实业务场景。案例为模拟案情,非真实裁判文书。

## 统一口径

制度文档(试用期 1/2/6 个月、加班工资 150/200/300%、年假 5/10/15 天、离职提前 30 日、差旅住宿 500/400/350 元、采购审批 5万/20万 分界、报销 30 个工作日、客户个人信息机密级等)与 `evaluation/qa.json` 的评估答案保持口径一致,便于评估可溯源。

## 入库建议

- `laws/*.pdf`:用 PDF 解析库(如 PyMuPDF / pdftotext)提取文本后再切片
- `policies/、contracts/、cases/` 下的 `.md` 可直接读取切片;`.docx` 可用 python-docx / docx2txt 解析
- 解析结果写入 `parsed/`,切块结果写入 `chunks/`,供向量化入库

## 生成方式

- 法律:运行 `tools/download_laws.py`(幂等,可断点重跑)
- 制度/合同/案例:AI 生成的 `.md` 源 + `pandoc` 转 `.docx`
- 评估集:`evaluation/qa.json`(JSON,100 条,UTF-8)
