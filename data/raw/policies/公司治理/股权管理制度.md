## 一、目的

为规范公司股权管理,明确注册资本、股权结构、股东权利与义务、股权转让、股权激励与分红等事项的管理程序,保护股东合法权益,促进公司规范治理,依据国家法律法规制定本制度。

## 二、编制依据

1. 《中华人民共和国公司法》;
2. 《中华人民共和国民法典》(合同编);
3. 《中华人民共和国市场主体登记管理条例》;
4. 《公司章程》。

## 三、定义

- **注册资本**:公司在登记机关登记的全体股东认缴的出资总额。
- **股权结构**:公司股东及其持股比例、出资方式、实缴情况等构成。
- **股东会决议**:股东会依法形成的决议文件,是公司重大事项决策的法定形式。
- **股权转让**:股东依法将其持有的公司股权让与他人的行为。
- **股权激励**:公司以授予股权、期权等方式激励核心员工的制度安排。

## 四、制度正文

### 4.1 股权结构与登记

1. 公司注册资本、各股东出资额、出资方式、持股比例、实缴期限均以《公司章程》及登记机关登记信息为准,必须保持清晰、一致;
2. 公司设置**股东名册**,载明股东姓名/名称、住所、出资额、出资方式、出资时间、持股比例、出资证明书编号,由董事会办公室统一管理;
3. 股东出资情况发生变化或股权变动的,应在变动发生后 30 日内依法向登记机关办理变更登记;未办理变更登记的,不得对抗善意第三人;
4. 股东依法享有权利以登记及股东名册记载为准。

### 4.2 股东权利

1. 股东依法享有资产收益、参与重大决策和选择管理者等权利;
2. 股东享有查阅、复制公司章程、股东会会议记录、董事会会议决议、监事会会议决议和财务会计报告的权利;
3. 股东按实缴出资比例分取红利;新增资本时,股东有权优先按照实缴出资比例认缴出资;
4. 股东权利行使应遵守法律法规与公司章程,不得滥用股东权利损害公司或其他股东利益。

### 4.3 股权转让程序

1. **书面通知**:股东向股东以外的人转让股权,应当就其股权转让事项**书面通知**其他股东征求同意,其他股东自接到书面通知之日起满三十日未答复的,视为同意转让;
2. **优先购买权**:经股东同意转让的股权,在同等条件下,其他股东有优先购买权;两个以上股东主张行使优先购买权的,协商确定各自的购买比例;协商不成的,按照转让时各自的出资比例行使优先购买权;
3. **股东会决议**:股东向股东以外的人转让股权,应依《公司章程》规定经股东会决议同意,并形成书面股东会决议;
4. **签署协议**:转让方与受让方签署《股权转让协议》,明确转让价款、支付方式、交割安排及债权债务承担;
5. **变更登记**:完成股权交割后,**依法办理工商变更登记**,并同步更新股东名册与出资证明书;
6. **涉密要求**:股权转让涉及公司商业秘密、技术信息的,应签署保密条款,按《商业秘密保护规定》执行。

### 4.4 股权质押与冻结

1. 股东以股权出质的,应依法办理股权出质登记,并通知公司;
2. 股权被司法冻结的,公司依法配合执行机关办理协助执行手续。

### 4.5 股权激励

1. 公司可根据发展需要实施股权激励,激励对象、授予条件、行权安排、回购机制由董事会制定方案,报股东会审议批准;
2. 股权激励应签订书面协议,明确服务期限、业绩条件、禁售期、离职处理及保密义务;
3. 激励对象离职、违反竞业限制或严重违纪的,公司有权按协议约定回购其激励股权。

### 4.6 分红管理

1. 公司税后利润分配依法定顺序进行:弥补亏损、提取法定公积金(提取比例 10%,累计额达到注册资本 50% 以上可不再提取)、经股东会决议提取任意公积金,再按股东实缴出资比例分配;
2. 利润分配方案由董事会提出,经股东会审议批准后实施;
3. 分红时间、方式依股东会决议执行,公司应依法代扣代缴相关税费。

## 五、流程

### 股权转让流程
```
转让方书面通知其他股东 → 征求同意(三十日答复期) → 确认优先购买权
→ 股东会决议 → 签署《股权转让协议》 → 工商变更登记 → 更新股东名册与出资证明书
```

## 六、责任与监督

1. **董事会办公室**:对股东名册、股权台账、股东会决议文件的管理负责;
2. **董事会/股东会**:对股权转让、股权激励、利润分配等重大事项决策负责;
3. **财务部**:对股权转让价款、分红、税务处理负责;
4. **法务与风控部**:对股权相关协议与决议的合法性审查负责;
5. 未按规定办理登记或擅自变动股权损害公司及其他股东利益的,依《公司法》及相关规定追责。

## 七、附则

1. 本制度由董事会办公室负责解释和修订;
2. 本制度自生效之日起施行,与《公司章程》不一致的,以《公司章程》为准;
3. 本制度未尽事宜,按《中华人民共和国公司法》及国家有关规定执行。

## 常见问题速查

**Q1:股东向股东以外的人转让股权,程序是什么?**
A:书面通知其他股东征求同意(三十日未答复视为同意)→ 其他股东同等条件下有优先购买权 → 经股东会决议 → 签署股权转让协议 → 办理工商变更登记并更新股东名册。

**Q2:股权转让后多久要办工商变更登记?**
A:股权发生变动后应在 30 日内依法办理变更登记;未办理的不得对抗善意第三人。

**Q3:公司利润分配的顺序是什么?**
A:弥补亏损 → 提取法定公积金(10%,累计达注册资本 50% 可不再提取)→ 提取任意公积金(如股东会决议)→ 按实缴出资比例分配。

**Q4:股权激励对象离职怎么办?**
A:按股权激励协议约定处理,公司有权按协议回购其激励股权;违反竞业限制或严重违纪的同样适用。

**Q5:注册资本和股权结构以什么为准?**
A:以《公司章程》及登记机关登记信息为准,公司须保持股东名册与登记信息一致、清晰。
