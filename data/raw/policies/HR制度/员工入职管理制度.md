# 华创智联科技有限公司员工入职管理制度

## 一、目的
为规范员工入职管理流程,保障公司与员工的合法权益,明确劳动合同签订、试用期及转正标准,特制定本制度。

## 二、编制依据
本制度依据《中华人民共和国劳动合同法》《中华人民共和国劳动合同法实施条例》《中华人民共和国社会保险法》等法律法规制定。

## 三、定义
- 3.1 入职:指经公司批准录用的人员,按约定时间到公司报到并办理相关手续、正式建立劳动关系的过程。
- 3.2 试用期:指劳动合同期限内,公司与员工相互考察约定的期间。
- 3.3 劳动合同:指员工与公司确立劳动关系、明确双方权利义务的书面协议。

## 四、制度正文
### 4.1 入职流程
入职流程依次为:发放Offer→入职资料提交→体检→劳动合同签订→保密协议签订→入职培训→账号开通。
1. 发放Offer:经录用审批通过后,由人力资源部向候选人发放书面录用通知(Offer),载明岗位、薪酬、入职时间等。
2. 入职资料:员工报到当日须提交身份证、学历学位证书、职称证书、离职证明、近期体检报告、银行卡及一寸照片等资料,人力资源部核验原件并留存复印件。
3. 体检:员工须提供三个月内的体检报告;特殊岗位按岗位要求安排专项体检,费用由公司承担。
4. 劳动合同签订:公司自用工之日起即与员工订立书面劳动合同,最迟不超过用工之日起30日。入职即签订劳动合同,签订保密协议,并完成人事档案建立。
5. 保密协议签订:员工入职时均须签订《保密协议》;涉及核心商业秘密岗位的,另行签订《竞业限制协议》。
6. 入职培训:人力资源部组织企业文化、规章制度、信息安全等培训,用人部门组织岗位技能培训。
7. 账号开通:行政部/IT部在劳动合同签订后1个工作日内开通办公系统账号、邮箱及门禁权限。

### 4.2 劳动合同期限与试用期
1. 劳动合同期限三个月以上不满一年的,试用期不得超过1个月;
2. 劳动合同期限一年以上不满三年的,试用期不得超过2个月;
3. 三年以上固定期限和无固定期限的劳动合同,试用期不得超过6个月;
4. 同一用人单位与同一劳动者只能约定一次试用期;
5. 以完成一定工作任务为期限的劳动合同或者劳动合同期限不满三个月的,不得约定试用期;
6. 试用期包含在劳动合同期限内。劳动合同仅约定试用期的,试用期不成立,该期限为劳动合同期限。

### 4.3 试用期工资
1. 员工试用期工资不得低于本单位相同岗位最低档工资的80%,或者不得低于劳动合同约定工资的80%;
2. 且不得低于公司所在地的最低工资标准。

### 4.4 试用期考核与转正
1. 考核内容:工作态度、岗位胜任能力、团队协作及遵守公司规章制度情况。
2. 考核时点:试用期届满前一周,由用人部门与人力资源部共同组织考核。
3. 转正:考核合格的,按期转正,公司下达《转正通知书》;考核不合格的,公司可依法解除劳动合同,并说明理由。
4. 试用期内员工主动辞职的,须提前3日书面通知公司。

## 五、流程图/步骤
```text
入职流程步骤:
① 发放Offer
② 报到并提交入职资料
③ 体检
④ 签订劳动合同(入职后30日内)
⑤ 签订保密协议
⑥ 入职培训
⑦ 开通账号与权限
⑧ 试用期考核 → 转正 / 解除
```

## 六、责任与监督
- 6.1 人力资源部:负责Offer发放、入职手续办理、劳动合同签订、人事档案建立及社保登记。
- 6.2 用人部门:负责岗位培训与试用期考核。
- 6.3 行政部/IT部:负责办公用品、系统账号与权限开通。
- 6.4 人力资源部负责监督本制度的执行,对违规行为责令整改并按规定处理。

## 七、附则
- 7.1 本制度由人力资源部负责解释与修订。
- 7.2 本制度自2026年1月1日起施行,原相关制度同时废止。
- 7.3 本制度未尽事宜,按国家法律法规及公司其他制度执行。
- 7.4 本制度为演示用示例制度,不构成法律文件。

## 八、常见问题速查
- Q1:试用期最长可以约定多久?A1:三年以上固定期限和无固定期限劳动合同,试用期最长不超过6个月(见本制度4.2.3条;《劳动合同法》第十九条)。
- Q2:公司最迟应在何时与我签订书面劳动合同?A2:自用工之日起30日内(见本制度4.1.4条;《劳动合同法》第十条)。
- Q3:试用期工资有什么下限?A3:不得低于本单位相同岗位最低档工资的80%或合同约定工资的80%,且不得低于当地最低工资标准(见本制度4.3条;《劳动合同法》第二十条)。
- Q4:同一员工能约定几次试用期?A4:只能约定一次(见本制度4.2.4条;《劳动合同法》第十九条)。
- Q5:试用期内我可以辞职吗?A5:可以,但须提前3日书面通知公司(见本制度4.4.4条;《劳动合同法》第三十七条)。
