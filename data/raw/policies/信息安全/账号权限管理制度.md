## 一、目的

为规范公司信息系统账号的开通、变更、注销与权限管理,落实最小权限原则,防止账号滥用、共用与越权访问,保障公司信息系统与数据安全,制定本制度。

## 二、编制依据

1. 《中华人民共和国个人信息保护法》;
2. 《中华人民共和国数据安全法》;
3. 《中华人民共和国网络安全法》;
4. 《华创智联科技有限公司密码管理规范》(HZ-XX-MM-2026-002);
5. 《华创智联科技有限公司数据访问管理制度》(HZ-XX-SJFH-2026-003)。

## 三、定义

- **账号**:员工访问公司信息系统所使用的账户标识(用户名/工号)及其认证凭据。
- **权限**:账号在信息系统内可执行的操作范围(查看、编辑、删除、导出、审批等)。
- **最小权限原则**:账号仅被授予完成本职工作所必需的最小权限。
- **权限分级**:按"公开/内部/机密"三级数据及业务岗位需要划分的权限等级。
- **共用账号**:多个人员共同使用同一账号登录系统的行为。

## 四、制度正文

### 4.1 账号开通流程

1. 新员工入职时,由用人部门提出申请,填写《账号开通申请单》,注明岗位、所需系统及权限范围;
2. 经部门负责人审批后,由信息技术部开通账号;涉及机密级数据访问权限的,须另行经数据主管与法务与风控部审批;
3. 账号开通应坚持**一人一号**,严禁共用账号;
4. 默认密码按《密码管理规范》执行,首次登录强制修改。

### 4.2 权限分级与最小授权

1. 系统权限按岗位职责与数据级别授予:

| 数据级别 | 说明 | 默认访问 |
| --- | --- | --- |
| 公开 | 公司对外公开信息 | 全体员工 |
| 内部 | 仅限公司内部使用 | 相关岗位员工 |
| 机密 | 商业秘密、客户个人信息等 | 仅授权人员,且须最小授权 |

2. **客户个人信息属机密级**,普通员工默认不得访问;确需访问的须按最小授权原则单独申请,经审批并审计留痕;
3. 权限授予与岗位职责匹配,杜绝"全权账号""超级账号"非必要存在;
4. 高权限账号(系统管理员、数据库管理员)应单独管理、定期复核,账号使用人不得以管理员权限访问业务数据(运维必需且留痕的除外)。

### 4.3 账号与权限变更

1. 员工岗位调整、职务变动时,用人部门应在 3 个工作日内申请调整其账号权限;
2. 涉及机密级数据权限变动的,须重新履行审批程序;
3. 任何权限变更由信息技术部在系统中留痕,记录变更前后权限及审批人。

### 4.4 离职账号处理

1. **离职员工账号即时停用**:员工离职当日(最迟不超过次日 9:00 前),由人力资源部通知信息技术部停用其全部系统账号;
2. 账号停用后,由信息技术部回收全部权限,并按规定保留审计日志;
3. 离职人员不得继续使用原账号;擅自继续使用的按违规处理;
4. 调岗员工在账号未完成调整前,不得继续使用与原岗位不匹配的高权限。

### 4.5 季度权限审计

1. 信息技术部每季度对全公司账号与权限进行一次审计,生成《权限审计报告》;
2. 审计重点:离职/转岗人员账号是否已停用或调整、是否存在越权权限、是否存在休眠账号(连续 90 天未使用)、是否存在共用账号;
3. 审计发现的问题应在审计报告出具后 10 个工作日内完成整改;
4. 审计报告报分管副总及审计部备案。

### 4.6 禁止共用账号与违规处理

1. 严禁员工之间共用账号、借用账号或代替他人登录;
2. 严禁将账号密码告知他人(含外单位人员);
3. 违反本制度造成数据泄露或安全事件的,依情节给予警告、记过、解除劳动合同等处分,并承担相应法律责任。

## 五、流程

```
入职/转岗/离职 → 提出申请(开通/变更/停用) → 部门负责人审批 → 数据主管/法务审批(机密权限)
→ 信息技术部执行 → 系统留痕 → 季度权限审计 → 整改
```

## 六、责任与监督

1. **用人部门**:对申请开通/变更/停用的及时性与真实性负责;
2. **人力资源部**:对入职信息推送、离职通知的及时性负责;
3. **信息技术部**:对账号执行、权限回收、审计留痕负责;
4. **数据主管/法务与风控部**:对机密级数据权限审批负责;
5. **审计部**:对季度权限审计执行情况进行监督。

## 七、附则

1. 本制度由信息技术部负责解释和修订;
2. 本制度自生效之日起施行;
3. 本制度未尽事宜,按国家法律法规及公司其他制度执行。

## 常见问题速查

**Q1:员工离职,账号什么时候停用?**
A:离职当日停用,最迟不超过次日 9:00 前,由人力资源部通知信息技术部执行并回收全部权限。

**Q2:普通员工能访问客户个人数据吗?**
A:不能。客户个人信息属机密级,普通员工不得访问;确需访问须最小授权+审批+审计留痕。

**Q3:账号可以借用给同事吗?**
A:严禁。坚持一人一号,禁止共用账号、借用账号或代替他人登录。

**Q4:权限审计多久做一次?**
A:每季度一次,重点检查离职账号、越权权限、休眠账号与共用账号。

**Q5:权限授予遵循什么原则?**
A:最小权限原则,仅授予完成本职工作所必需的最小权限。
