## 一、目的

为规范公司数据脱敏的范围、方式与使用场景,防止客户个人信息与敏感数据在开发、测试、演示、外包等非生产环境中泄露,落实《个人信息保护法》合规要求,制定本办法。

## 二、编制依据

1. 《中华人民共和国个人信息保护法》;
2. 《中华人民共和国数据安全法》;
3. 《中华人民共和国网络安全法》;
4. 《华创智联科技有限公司数据访问管理制度》(HZ-XX-SJFH-2026-003);
5. 《华创智联科技有限公司用户信息保护规范》(HZ-XX-YH-2026-004)。

## 三、定义

- **数据脱敏**:对敏感数据通过掩码、泛化、替换等方式进行处理,使处理后的数据无法直接识别特定个人,且不影响业务使用。
- **掩码**:将字段的部分字符以符号(如\*)替换,如手机号 138****1234。
- **泛化**:将精确值替换为范围或类别,如将精确年龄替换为年龄段、精确地址替换为城市或区级。
- **替换**:以虚构数据替换真实数据,保持字段格式与业务逻辑一致,如将真实姓名替换为随机姓名。
- **脱敏数据**:经过脱敏处理、无法用于识别特定个人的数据。

## 四、制度正文

### 4.1 脱敏范围与字段

以下**敏感字段**在非生产环境下使用前必须脱敏:

1. **手机号**;
2. **身份证号**;
3. **银行卡号**;
4. **住址**(精确到门牌号或小区的详细地址);
5. 其他可识别特定个人的字段,包括:姓名、电子邮箱、IP 地址、健康信息、行踪轨迹、生物识别信息、用户账号等。

### 4.2 脱敏方式

| 方式 | 说明 | 示例 |
| --- | --- | --- |
| 掩码 | 保留部分字符,其余以\*替换 | 手机号 138****1234;身份证 110***********1234 |
| 泛化 | 精确值替换为范围或类别 | 年龄 29 岁→20-30 岁;地址→所在城市 |
| 替换 | 以保持格式的虚构数据替换 | 姓名→随机姓名;邮箱→随机邮箱 |

脱敏要求:

1. 脱敏后数据应**不可逆**,无法通过脱敏数据还原出真实数据;
2. 脱敏后数据应保持原有格式与业务逻辑,保证测试、演示、开发可用;
3. 同一数据集内应保持脱敏一致性(如同一人的多次出现使用相同的替换值),必要时建立脱敏映射表并加密保管;
4. 生产环境与脱敏环境数据隔离,脱敏数据不得反向关联生产数据。

### 4.3 脱敏适用场景

以下场景**必须使用脱敏数据**,禁止使用真实明文数据:

1. **测试环境**:系统开发、测试、联调、验收使用的数据;
2. **演示场景**:产品演示、对外展示、培训、会议演示使用的数据;
3. **外包与第三方**:交付给外包服务商、第三方开发或维护人员使用的数据;
4. 数据分析、建模(非必要使用明文时)及内部培训等场景。

### 4.4 脱敏责任与流程

1. 数据使用部门在申请非生产环境数据前,须填写《数据脱敏申请单》,注明用途、数据范围与脱敏方式;
2. 信息技术部负责实施脱敏,并对脱敏效果进行校验(抽查确认敏感字段已无法识别);
3. 脱敏实施过程留痕,记录脱敏规则、执行人、执行时间与校验结果;
4. 确需使用真实明文数据的(如生产验证、合规核查),须按机密级数据访问流程审批,并全程审计留痕;
5. 脱敏数据仍应按内部数据管理,不得公开传播。

### 4.5 外包与第三方脱敏要求

1. 向外包、第三方提供数据的,须在合同中约定数据脱敏要求与保密义务;
2. 外包人员使用脱敏数据期间,公司保留审计与抽检权利;
3. 项目结束后,外包方应归还或销毁其持有的脱敏数据(含副本)。

### 4.6 违规处理

1. 未脱敏即向测试、演示、外包场景提供真实敏感数据,或擅自将脱敏数据还原的,视情节给予警告、记过、解除劳动合同等处分;
2. 造成个人信息泄露、侵犯用户权益的,依《个人信息保护法》承担法律责任,涉嫌犯罪的移送司法机关;
3. 违规情形纳入绩效与档案,并抄送法务与风控部。

## 五、流程

```
数据需求申请 → 用途评估 → 填写《数据脱敏申请单》 → 信息技术部实施脱敏
→ 脱敏效果校验 → 交付使用 → 使用留痕 → 项目结束归还/销毁
```

## 六、责任与监督

1. **数据使用部门**:对申请用途真实性与脱敏数据合理使用负责;
2. **信息技术部**:对脱敏实施、校验、映射表保管负责;
3. **法务与风控部**:对脱敏制度执行、外包合同条款与违规追责负责;
4. **审计部**:每季度抽查脱敏执行记录与校验结果,核查是否发生未脱敏使用真实数据的违规情形。

## 七、附则

1. 本办法由信息技术部负责解释和修订;
2. 本办法自生效之日起施行;
3. 本办法未尽事宜,按《个人信息保护法》《数据安全法》及公司其他制度执行。

## 常见问题速查

**Q1:哪些字段必须脱敏?**
A:手机号、身份证号、银行卡号、精确住址,以及其他可识别特定个人的姓名、邮箱、IP、健康信息等敏感字段。

**Q2:脱敏有哪几种方式?**
A:掩码(如 138\*\*\*\*1234)、泛化(精确值变范围)、替换(虚构数据保持格式),脱敏后不可逆且保持业务可用。

**Q3:测试环境能用真实用户数据吗?**
A:不能。测试、演示、外包与第三方场景必须使用脱敏数据。

**Q4:谁负责实施脱敏?**
A:信息技术部负责实施与校验,数据使用部门填写《数据脱敏申请单》说明用途。

**Q5:外包项目结束后脱敏数据怎么处理?**
A:外包方应归还或销毁其持有的脱敏数据(含副本),公司保留审计与抽检权利。

**Q6:未脱敏就使用真实数据有什么后果?**
A:属违规行为,视情节警告、记过直至解除劳动合同;造成泄露或侵犯权益的依《个人信息保护法》承担法律责任。
