## 一、目的

为规范公司对用户个人信息的收集、使用、存储、传输、共享与删除等处理活动,落实《个人信息保护法》合规要求,保障用户个人信息权益,防范个人信息泄露与违法处理风险,制定本规范。

## 二、编制依据

1. 《中华人民共和国个人信息保护法》;
2. 《中华人民共和国数据安全法》;
3. 《中华人民共和国网络安全法》;
4. 《中华人民共和国民法典》(人格权编关于个人信息的规定);
5. 《华创智联科技有限公司数据访问管理制度》(HZ-XX-SJFH-2026-003);
6. 《华创智联科技有限公司数据脱敏管理办法》(HZ-XX-TM-2026-005)。

## 三、定义

- **个人信息**:以电子或其他方式记录的与已识别或可识别的自然人有关的各种信息,如姓名、手机号、身份证号、住址、行踪等。
- **敏感个人信息**:一旦泄露或非法使用容易导致自然人的人格尊严或人身、财产安全受到危害的个人信息,如生物识别信息、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹以及不满十四周岁未成年人的个人信息。
- **个人信息处理者**:在个人信息处理活动中自主决定处理目的、处理方式的组织、个人。公司为用户个人信息处理者。
- **最小必要**:处理个人信息应当具有明确、合理的目的,并限于实现处理目的的最小范围。
- **告知同意**:处理个人信息前,应当以显著方式、清晰易懂的语言真实、准确、完整地告知信息处理规则并取得同意。

## 四、制度正文

### 4.1 收集最小必要

1. 公司收集个人信息应当限于实现业务目的所必需的最小范围,不得过度收集;
2. 收集前须评估处理目的与必要范围,填写《个人信息处理影响评估表》;
3. 不得以拒绝提供服务为由强制收集与业务无关的个人信息;
4. 收集未成年个人信息的,依法取得监护人同意,并适用最严格保护。

### 4.2 告知同意

1. 收集个人信息前,应通过隐私政策、用户协议、弹窗提示等方式**告知**处理者身份、处理目的、处理方式、信息种类、保存期限、用户权利及投诉渠道;
2. 取得用户的**知情同意**,同意应当自愿、明确、具体;
3. 处理目的、方式或信息种类发生变化的,应重新取得同意;
4. 处理敏感个人信息的,应取得用户**单独同意**,并告知必要性及对用户的影响。

### 4.3 敏感信息特别保护

1. 身份证号、手机号、银行卡号、精确住址、健康信息、生物识别信息等敏感个人信息,须经单独同意后方可处理;
2. 敏感个人信息在业务办理完成后应尽量及时删除或脱敏;
3. 处理敏感个人信息的场景、目的、期限应单独记录备查。

### 4.4 存储与安全措施

1. 个人信息应存储于公司符合安全等级要求的服务器与数据库,采取加密、访问控制、防泄漏等技术措施;
2. **个人信息一律属机密级数据**,访问须最小授权+审批+审计留痕,普通员工不得访问;
3. 个人信息保存期限为实现目的所必需的最短时间;期限届满或目的实现后,依法删除或匿名化;
4. 向第三方提供、委托处理、共享个人信息的,须签订协议明确处理目的、期限、方式与保护义务,并进行影响评估,同时依法向用户告知并取得同意(如需)。

### 4.5 员工行为规范

1. 员工仅可在授权范围内处理与工作相关的个人信息,**不得私自复制、下载、外发用户个人信息**;
2. 禁止将个人信息用于与工作无关的个人用途,禁止将个人信息提供给亲友、自媒体或第三方;
3. 测试、演示、外包等场景需要使用个人信息的,一律使用**脱敏数据**,不得使用真实个人信息明文;
4. 员工发现个人信息泄露或疑似泄露的,须立即报告部门负责人及法务与风控部。

### 4.6 用户权利保障

1. 公司应为用户提供查阅、复制、更正、删除其个人信息,以及撤回同意、注销账户、投诉举报等渠道;
2. 受理用户权利请求后,应在 15 个工作日内予以处理并答复;
3. 个人信息处理规则(隐私政策)更新时,应通过适当方式告知用户。

### 4.7 违规追责

1. 违反本规范收集、使用、泄露用户个人信息的,视情节给予警告、记过、解除劳动合同等处分;
2. 造成用户个人信息权益损害的,公司依法承担赔偿责任,并有权向有过错员工追偿;
3. 违反《个人信息保护法》规定的,依法承担行政责任;涉嫌犯罪的移送司法机关。

## 五、流程

```
业务目的评估 → 影响评估 → 告知同意(敏感信息单独同意) → 最小必要收集 → 加密存储
→ 授权访问与留痕 → 脱敏用于测试/演示/外包 → 期限届满删除/匿名化 → 用户权利响应
```

## 六、责任与监督

1. **各业务部门**:对个人信息收集的必要性、合规告知与使用负责;
2. **法务与风控部**:对隐私政策、影响评估、违规追责与合规咨询负责;
3. **信息技术部**:对加密、权限、留痕与安全技术措施负责;
4. **审计部**:每季度对个人信息处理活动与访问日志进行合规审计;
5. 涉及个人信息的项目上线前,须经法务与风控部合规评审。

## 七、附则

1. 本规范由法务与风控部负责解释和修订;
2. 本规范自生效之日起施行;
3. 本规范未尽事宜,按《个人信息保护法》及国家有关规定执行。

## 常见问题速查

**Q1:收集用户信息应当遵循什么原则?**
A:最小必要原则,仅收集实现业务目的所必需的最小范围,并事先告知取得同意。

**Q2:处理敏感个人信息需要什么条件?**
A:须取得用户单独同意,告知必要性及影响,并采取更严格保护措施,尽量及时删除或脱敏。

**Q3:测试或演示能使用真实用户信息吗?**
A:不能。测试、演示、外包等场景必须使用脱敏数据。

**Q4:员工可以私自复制、外发用户信息吗?**
A:严禁。员工仅可在授权范围内处理信息,私自复制、下载、外发属违规行为。

**Q5:用户要求删除其个人信息,公司要多久处理?**
A:应在 15 个工作日内处理并答复;保存期限届满或目的实现后依法删除或匿名化。

**Q6:违反本规范有什么后果?**
A:视情节警告、记过直至解除劳动合同,公司可向过错员工追偿;违反《个人信息保护法》的依法承担行政责任,涉嫌犯罪移送司法机关。
