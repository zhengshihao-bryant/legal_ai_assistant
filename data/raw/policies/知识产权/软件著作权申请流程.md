## 一、目的

为规范公司软件著作权的申请、登记与维护工作,明确申请材料、申请步骤、周期、费用与权利归属,保护公司软件成果的合法权利,促进软件资产管理与运用,制定本流程。

## 二、编制依据

1. 《中华人民共和国著作权法》;
2. 《计算机软件保护条例》;
3. 《计算机软件著作权登记办法》;
4. 《华创智联科技有限公司技术成果管理制度》(HZ-ZS-JSCG-2026-002)。

## 三、定义

- **软件著作权**:软件开发者依法对其开发的计算机软件享有的发表权、署名权、修改权、复制权、发行权、出租权、信息网络传播权、翻译权等权利。
- **中国版权保护中心**:负责计算机软件著作权登记的国家版权登记机构,实行在线申请。
- **著作权归属**:软件著作权的权利主体归属,区分职务软件(归属单位)与非职务软件(归属个人)。

## 四、制度正文

### 4.1 申请范围与条件

1. 凡属于职务技术成果、由公司主导开发的软件,均应申请软件著作权登记;
2. 申请登记的软件应已完成开发并通过验收,源代码与文档齐备,具备登记的实质性要件;
3. 以下软件优先安排登记:对外销售或交付客户的软件、对外授权许可的软件、作为公司核心产品的软件、参与招投标或资质申报需要的软件。

### 4.2 申请材料

1. **软件著作权登记申请表**:通过中国版权保护中心在线填报,包括软件全称、简称、版本号、开发完成日期、首次发表日期、开发方式(独立/合作/委托)、著作权人、权利取得方式等信息;
2. **源代码**:提交前、后各连续 30 页源代码(共 60 页),每页不少于 50 行;不足 60 页的,提交全部源代码;源代码须去除注释后的页面并统一格式;
3. **软件说明书/文档**:包括软件操作说明书、设计说明书、用户手册等文档,一般提交前、后各 30 页;
4. **主体资格证明**:营业执照副本复印件等;
5. 委托他人开发的,还需提供委托开发合同及权利归属约定。

### 4.3 申请步骤(中国版权保护中心在线申请)

1. **在线注册**:登录中国版权保护中心官网(www.ccopyright.com.cn)注册账号并进行实名认证;
2. **在线填报**:进入"计算机软件著作权登记"栏目,填写软件登记申请表并上传相关材料;
3. **提交申请**:确认信息无误后在线提交申请;
4. **缴费**:按规定缴纳登记费用(官方受理费);
5. **受理与审查**:登记机构对申请材料进行形式审查,材料不齐的限期补正(一般为 30 日内);
6. **领取登记证书**:审查通过后,领取《计算机软件著作权登记证书》。

### 4.4 办理周期与费用

1. 自申请受理之日起,登记机构在 **约 60 日** 内完成审查并决定是否登记;
2. 需补正材料的,补正期间不计入审查期限,办理周期相应顺延;
3. 申请费用:按登记机构公布的标准缴纳登记费(官方受理费,含证书费);公司鼓励通过加急等合法渠道满足紧急商务需要,但加急费用须经知识产权部负责人审批;
4. 登记费用由公司承担,列支研发费用。

### 4.5 著作权归属

1. 员工执行公司任务或主要利用公司物质技术条件开发的软件,属**职务软件**,著作权归**公司**所有,作者享有署名权;
2. 委托开发的软件,著作权归属按委托合同约定;未约定的,著作权归受托人;
3. 合作开发的软件,著作权归属按合作协议约定;
4. 员工在职期间开发的与公司业务相关软件,应在申请前向知识产权部申报权属,避免归属纠纷;
5. 涉及客户个人信息的软件,登记及后续使用须遵守《个人信息保护法》及《用户信息保护规范》。

### 4.6 登记的意义

1. **权利证明**:登记证书是软件著作权权属的初步证明,便于在侵权纠纷中举证维权;
2. **资产保护**:明确软件资产权属,防止核心技术被抄袭或主张权利时陷入被动;
3. **商务运用**:登记是软件产品入市、招投标、高新技术企业认定、软件企业资质申报、价值评估与许可转让的重要材料;
4. **管理与激励**:登记情况纳入研发部门与个人绩效考核,按《技术成果管理制度》给予奖励。

## 五、流程

```
研发部门提交申请 → 知识产权部形式审查 → 权属确认 → 准备材料(源代码/文档/申请表)
→ 中国版权保护中心在线申请 → 缴费 → 受理审查(约60日) → 领取登记证书 → 登记台账归档
```

## 六、责任与监督

1. **研发部门**:负责提供完整、准确的源代码与文档,对申请软件的技术真实性负责;
2. **知识产权部**:负责申请统筹、材料审核、在线申报、费用管理及证书归档;
3. **法务与风控部**:负责权属界定、委托/合作开发合同审查;
4. **审计部**:每年度核查软件著作权台账,评估登记覆盖情况;
5. 因材料弄虚作假导致登记被撤销或给公司造成损失的,追究相关责任。

## 七、附则

1. 本流程由知识产权部负责解释和修订;
2. 本流程自生效之日起施行;
3. 本流程未尽事宜,按《计算机软件著作权登记办法》及国家有关规定执行。

## 常见问题速查

**Q1:软件著作权登记需要哪些材料?**
A:登记申请表、源代码(前后各连续 30 页,每页不少于 50 行)、软件说明书/文档、主体资格证明;委托开发的还需委托合同。

**Q2:办理周期大概多久?**
A:自受理之日起约 60 日完成审查;需补正的补正期间不计入。

**Q3:如何申请?**
A:通过中国版权保护中心官网注册实名认证后在线填报、提交、缴费。

**Q4:员工开发的软件著作权归谁?**
A:职务软件(执行公司任务或主要利用公司物质技术条件开发的)著作权归公司所有,作者享有署名权。

**Q5:登记费用由谁承担?**
A:由公司承担,列支研发费用;加急等额外费用须经知识产权部负责人审批。

**Q6:软著登记有什么意义?**
A:作为权属初步证明便于维权,保护软件资产,满足招投标、资质申报、价值评估与许可转让等商务需求。
