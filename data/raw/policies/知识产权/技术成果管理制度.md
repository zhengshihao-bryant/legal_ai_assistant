## 一、目的

为加强公司技术成果的管理与保护,明确职务技术成果的归属、研发记录、申报流程、成果奖励与转化许可机制,激励技术创新,防止技术成果流失,制定本制度。

## 二、编制依据

1. 《中华人民共和国专利法》;
2. 《中华人民共和国著作权法》;
3. 《计算机软件保护条例》;
4. 《中华人民共和国反不正当竞争法》;
5. 《中华人民共和国促进科技成果转化法》;
6. 《华创智联科技有限公司软件著作权申请流程》(HZ-ZS-RJZZ-2026-001);
7. 《华创智联科技有限公司商业秘密保护规定》(HZ-ZS-SM-2026-003)。

## 三、定义

- **技术成果**:公司及员工在研发、生产、经营过程中形成的专利、软件著作权、技术秘密、技术方案、图纸、配方、算法、数据集等技术智力成果。
- **职务技术成果**:执行公司工作任务或主要利用公司物质技术条件完成的技术成果。
- **研发记录**:研发过程中的实验数据、设计文档、代码版本、会议纪要等原始记录。
- **成果转化**:将技术成果应用于生产、许可、转让、作价投资等实现价值的过程。

## 四、制度正文

### 4.1 职务技术成果归属

1. **职务技术成果归属公司**:员工执行公司工作任务,或主要利用公司的物质技术条件完成的发明创造、软件、技术秘密等,其权利归**公司**所有;
2. 员工离职后 1 年内作出与其在公司承担的本职工作或原任务有关的发明创造,依法仍属职务技术成果,归公司所有;
3. 职务技术成果的发明人/设计人享有署名权、获得奖励与报酬的权利;
4. 合作开发、委托开发成果的归属按合同约定,合同未约定的依法律规定处理;
5. 员工入职时及项目立项时,应签署技术成果权属与保密相关文件,明确权属约定。

### 4.2 研发记录管理

1. 研发项目应建立**研发记录本**或电子研发记录系统,记录实验过程、设计思路、数据、代码版本、问题与解决方案;
2. 研发记录应连续、真实、可追溯,标注日期、项目名称与记录人;
3. 关键研发节点应留存评审记录,评审资料作为技术成果权属与新颖性判定的重要证据;
4. 研发记录属公司机密级资料,按《商业秘密保护规定》管理,不得随意带离公司或外传。

### 4.3 专利与软著申报流程

1. **成果申报**:研发部门在技术成果完成后,及时向知识产权部提交《技术成果申报表》,附技术交底材料;
2. **可专利性评估**:知识产权部会同技术专家评估新颖性、创造性、实用性,决定是否申请专利或采取技术秘密保护;
3. **专利申报**:按《专利法》及国家知识产权局要求提交专利申请材料,委托专利代理机构办理的,由知识产权部统一对接;
4. **软著申报**:软件类成果按《软件著作权申请流程》办理登记;
5. **申报时限**:计划申报专利的技术成果,在对外发表论文、公开演示、对外销售等公开行为**之前**提出申报,避免丧失新颖性;
6. **台账管理**:知识产权部建立技术成果与知识产权台账,登记申请号、状态、权属、缴费情况。

### 4.4 成果奖励

1. 对职务技术成果完成人,公司依法给予奖励与报酬:
   - 被授予专利权的,自专利权公告之日起 3 个月内,对发明人/设计人发放一次性奖金;
   - 软件著作权登记成功的,对完成人给予一次性奖励;
   - 成果实施转化产生经济效益的,按净收益的一定比例给予发明人/设计人奖励,具体比例由公司另行规定;
2. 奖励情况记入员工档案,作为晋升、评优的参考。

### 4.5 成果转化与许可

1. 技术成果对外转化(转让、许可、作价投资)须经知识产权部评估、法务审查,并按以下权限审批:单项金额 5 万元以下的由总经理授权部门负责人批准;5 万元(含)至 20 万元的由分管副总批准;20 万元(含)以上的报总经理办公会(或董事会)审批;
2. 技术许可/转让合同应明确权利范围、期限、使用费、保密与违约责任,并约定不侵权保证;
3. 成果转化收入依法纳入公司财务核算,并按第 4.4 条落实完成人奖励;
4. 向境外转让或许可涉及核心技术的,应按国家技术出口有关规定履行程序。

### 4.6 保密要求

1. 尚未公开申报或已作为技术秘密保护的技术成果,属公司商业秘密,按《商业秘密保护规定》执行分级与保密措施;
2. 技术成果对外披露、参加展会、论文发表等,须经知识产权部审批,防止泄密与丧失新颖性。

## 五、流程

```
研发立项 → 研发记录 → 成果完成 → 提交申报表 → 权属确认 → 可专利性/保护方式评估
→ 专利/软著申报 → 授权/登记 → 台账归档 → 奖励发放 → 转化与许可(如适用)
```

## 六、责任与监督

1. **研发部门**:对研发记录的真实性、成果申报的及时性负责;
2. **知识产权部**:对申报组织、台账管理、保密评估、奖励核算负责;
3. **法务与风控部**:对成果权属合同、转化合同合法性负责;
4. **审计部**:每年度核查技术成果台账、申报与奖励发放情况;
5. 员工隐匿、私自处置职务技术成果或违反保密义务的,依《商业秘密保护规定》及公司制度追责。

## 七、附则

1. 本制度由知识产权部负责解释和修订;
2. 本制度自生效之日起施行;
3. 本制度未尽事宜,按国家法律法规及公司其他制度执行。

## 常见问题速查

**Q1:职务技术成果归谁所有?**
A:员工执行公司任务或主要利用公司物质技术条件完成的技术成果,权利归公司所有;离职后 1 年内作出与原职务有关的发明创造仍属职务成果。

**Q2:研发记录有什么要求?**
A:连续、真实、可追溯,记录实验过程、数据、代码版本与评审,属机密级资料,不得外传。

**Q3:专利申报要在什么时候提出?**
A:在对外发表论文、公开演示、销售等公开行为之前提出,避免丧失新颖性。

**Q4:技术成果有奖励吗?**
A:有。授权专利、软著登记给予一次性奖励;成果转化产生效益的按净收益比例给予完成人奖励。

**Q5:技术成果对外转化由谁审批?**
A:按金额分级:5 万元以下部门负责人、5 万元(含)至 20 万元分管副总、20 万元(含)以上总经理办公会(或董事会)审批。
