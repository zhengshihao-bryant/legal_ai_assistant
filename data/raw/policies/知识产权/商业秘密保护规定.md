## 一、目的

为保护公司商业秘密,规范商业秘密的界定、保密措施、员工保密义务与竞业限制安排,防范商业秘密泄露给公司造成损失,依据国家法律法规制定本规定。

## 二、编制依据

1. 《中华人民共和国反不正当竞争法》(第九条、第十七条等);
2. 《中华人民共和国民法典》(合同编关于保密与违约责任的规定);
3. 《中华人民共和国劳动合同法》;
4. 《中华人民共和国刑法》(侵犯商业秘密罪相关规定);
5. 《华创智联科技有限公司数据访问管理制度》(HZ-XX-SJFH-2026-003)。

## 三、定义

- **商业秘密**:不为公众所知悉、具有商业价值并经权利人采取相应保密措施的技术信息、经营信息等商业信息。
- **技术信息**:技术方案、工艺流程、配方、源代码、算法、设计图纸、研发记录、实验数据等。
- **经营信息**:客户名单、经营策略、财务数据、招投标文件、合同报价、采购渠道、市场调研等。
- **保密义务**:相关人员对所知悉的保密信息负有的不得披露、使用、允许他人使用的义务。
- **竞业限制**:与负有保密义务的员工约定,离职后一定期限内不得从事与公司有竞争关系的业务的安排。

## 四、制度正文

### 4.1 商业秘密的范围

公司商业秘密包括但不限于:

1. **技术信息**:源代码、架构设计、算法模型、工艺参数、配方、技术图纸、研发数据、测试方案等;
2. **经营信息**:客户名单及客户信息、供应商信息、报价体系、投标文件、经营策略、财务资料、对外合同中的保密条款内容等;
3. **管理信息**:公司内部管理流程、薪酬体系、投资计划、并购方案等;
4. **客户个人信息**:客户个人信息依据《个人信息保护法》及公司《用户信息保护规范》另行管理,同时按本规定作为机密级信息保护。

### 4.2 商业秘密分级与保密措施

公司对信息实行**公开/内部/机密**三级管理,商业秘密属**机密级**:

| 级别 | 范围 | 保密措施 |
| --- | --- | --- |
| 公开 | 公司对外公开的宣传资料、产品介绍等 | 无需特殊管理 |
| 内部 | 仅限公司内部使用的普通经营、技术信息 | 内部使用,不得外传 |
| 机密 | 商业秘密、客户个人信息、核心技术等 | 最小授权访问、访问留痕、物理隔离、专人管理 |

保密措施包括:

1. **权限控制**:机密级信息按最小授权原则控制访问权限,普通员工不得访问客户个人数据;确需访问的须最小授权+审批+审计留痕;
2. **物理保密**:机密资料存放于上锁文件柜或保密机房,严格控制复制、打印、携带外出;
3. **技术保密**:涉密系统启用访问控制、加密、审计日志;禁止使用个人设备、个人云盘存储涉密信息;
4. **标识管理**:涉密文件、载体标注"机密"字样;
5. **人员管理**:员工入职签署保密协议,离职办理保密与权限回收手续,离职即时回收账号权限。

### 4.3 员工保密义务

1. 员工在职期间及**离职后**,对其知悉的公司商业秘密负有保密义务;
2. 保密义务存续于劳动合同期内及劳动合同终止/解除之后,不因劳动关系消灭而免除;
3. 员工不得实施以下行为:
   - 将保密信息泄露给任何第三方,包括以口头、书面、电子方式传递;
   - 将保密信息用于与工作无关的个人用途;
   - 私自复制、下载、截取、外发保密信息;
   - 将客户个人信息带走或用于新雇主业务;
   - 引诱、帮助第三方获取公司保密信息。
4. 员工发现保密信息泄露或有泄露风险的,应立即报告部门负责人或法务与风控部。

### 4.4 竞业限制

1. 公司可与负有保密义务的高级管理人员、核心技术人员及其他负有保密义务的人员约定竞业限制条款;
2. **竞业限制期限自离职之日起不超过 2 年**;
3. 在竞业限制期限内,公司**按月给予经济补偿**,补偿标准不低于法律法规规定的最低标准;
4. 被限制人员不得入职与公司有竞争关系的单位,不得自营同类业务;
5. 竞业限制期间,公司可解除竞业限制;被限制人违反竞业限制的,按约定承担违约金并返还已付经济补偿。

### 4.5 违约责任

1. 员工违反保密义务的,公司有权要求其承担**违约责任**(支付违约金、赔偿损失),并可按公司制度给予处分;
2. 侵犯商业秘密给公司造成损失的,依《反不正当竞争法》第九条、第十七条要求侵权人承担赔偿责任;
3. 情节严重的,涉嫌《刑法》第二百一十九条之一规定的侵犯商业秘密罪等犯罪的,依法移送司法机关追究刑责。

### 4.6 泄密调查与追责流程

1. **报告受理**:任何部门或个人发现泄密迹象,须立即报告法务与风控部;
2. **应急止损**:法务与风控部会同信息技术部立即封禁相关账号、终止数据外传,评估影响范围;
3. **调查取证**:组成调查组,查阅审计日志、权限记录、访问留痕,询问相关人员,固定证据;
4. **责任认定**:依调查结果认定泄密行为与责任人,区分故意与过失;
5. **处理与追责**:按本规定第 4.5 条追究违约/侵权责任,涉及刑事犯罪的移送司法机关;
6. **整改**:针对暴露的管理漏洞完善保密措施,必要时开展全员保密培训。

## 五、流程

```
保密信息分级标识 → 权限控制与留痕 → 涉密人员保密协议/竞业限制 → 日常监督
→ 泄密报告 → 应急止损 → 调查取证 → 责任认定 → 追责整改
```

## 六、责任与监督

1. **各部门负责人**:对本部门涉密信息管理与员工保密教育负责;
2. **信息技术部**:对涉密系统权限、加密、审计日志负责;
3. **法务与风控部**:对保密协议、竞业限制、泄密调查与追责负责;
4. **人力资源部**:对员工入职保密协议签署、离职保密与权限回收负责;
5. **审计部**:每季度抽查涉密信息访问与权限变更记录。

## 七、附则

1. 本规定由法务与风控部负责解释和修订;
2. 本规定自生效之日起施行;
3. 本规定未尽事宜,按《反不正当竞争法》《劳动合同法》等法律法规及公司其他制度执行。

## 常见问题速查

**Q1:公司的商业秘密包括哪些?**
A:技术信息(源代码、算法、配方、图纸等)和经营信息(客户名单、报价、招投标、财务数据等),属机密级信息。

**Q2:员工离职后还有保密义务吗?**
A:有。保密义务存续于劳动合同期内及离职后,不因劳动关系消灭而免除。

**Q3:竞业限制期限多长?要支付补偿吗?**
A:自离职之日起不超过 2 年,公司须按月支付不低于法定标准的经济补偿。

**Q4:违反保密义务要承担什么责任?**
A:承担违约责任(违约金、赔偿损失);依《反不正当竞争法》第九条、第十七条承担赔偿责任;情节严重涉嫌犯罪的移送司法机关。

**Q5:普通员工能访问客户个人数据吗?**
A:不能。客户个人信息属机密级,普通员工不得访问;确需访问须最小授权+审批+审计留痕。

**Q6:发现泄密怎么办?**
A:立即报告部门负责人或法务与风控部,由公司启动应急止损、调查取证与追责程序。
